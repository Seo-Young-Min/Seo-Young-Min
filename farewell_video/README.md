## 배경음 넣기
배경음 저작권 때문에 영상에는 음악이 들어 있지 않습니다. 직접 구매·보유한 음원 파일로 합성하세요.

```bash
python make_video.py --media <사진·영상 폴더> --font-dir <폰트 폴더> \
    --out farewell.mp4 --music "시월의 어느 멋진 날에.mp3"
```
