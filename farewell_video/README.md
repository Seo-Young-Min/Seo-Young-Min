# 시월의 어느 멋진 날에 — 빅데이터 조사 과정 8개월의 여정

- 1920×1080 / 30fps / 약 1분 56초, 14개 장면, 장면 사이 1초 크로스페이드
- 사진·동영상은 확대·이동 없이 원본 그대로 (확대·이동 시 잔무늬가 반짝거림)
- 4~6번 장면은 `anim.py`로 그린 한국풍(한지·수묵·단청 색감) 스마트팜 애니메이션: 비닐하우스 센서 데이터, 두루마리 측정 기록, 오류값 검수·"검수완료" 도장
- 자막 서체: 나눔명조 ExtraBold (SIL OFL), 모든 줄 같은 크기로 균형
- 자막 길이는 초당 약 4.5음절(보통 사람이 편하게 읽는 속도) 기준으로 장면 길이를 자동 계산
- 시비 「강 2」·「광장」은 시비 전체가 보이게 하고 자막은 시비 아래에 배치
- 배경음악: `make_music.py`로 직접 작곡·합성한 G장조 3/4박 피아노 왈츠(현악 패드 포함) — 저작권 걱정 없음, 엔딩에 "♪ 배경음악: 10월에 만든 3박자 왈츠 곡" 표기

## 만들기

```bash
L=$(python make_video.py --media <사진·영상 폴더> --print-length)   # 영상 길이(초)
python make_music.py --seconds $L --out bgm.wav                     # 길이에 맞춘 배경음악
python make_video.py --media <사진·영상 폴더> --font-dir <폰트 폴더> --music bgm.wav --out farewell.mp4
```

다른 음원을 쓰려면 `--music`에 mp3 등을 주면 됩니다. 영상 길이에 맞춰 잘리고 끝 4초는 페이드아웃됩니다.
자막 문구·순서는 `make_video.py`의 `SCENES` 목록에서 고칩니다.

## 휴대폰용 세로 영상 (1080×1920)

```bash
python make_vertical.py --media <사진·영상 폴더> --font-dir <폰트 폴더> --music bgm.wav --out farewell_세로.mp4
```

장면·자막·길이는 `make_video.py`와 같습니다. 위쪽에 사진·영상, 아래쪽에 큰 자막(70px, 긴 줄은 자동 줄바꿈)을 두고,
배경은 같은 장면을 흐리게 깝니다. 타이틀의 부제·날짜, 엔딩의 배경음악 표기도 휴대폰에서 잘 보이게 키웠습니다.
